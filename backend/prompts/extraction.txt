      * PATTERNED UNIT CELLS WITH MORE THAN ONE SHAPED ELEMENT (not a vertical stack): many metasurface/metamaterial designs are NOT simple flat layers at all -- a single functional layer is instead an IN-PLANE PATTERN made of two or more distinctly-shaped resonator elements of the same or different materials sharing one unit cell (e.g. "a crossed rod and four fan-shaped silicon blocks", "a nanodisk surrounded by a split-ring", "a bar resonator alongside a ring resonator"). Collapsing this down to just one generic "Material(height)" token silently deletes a real structural element (which shape corresponds to which resonance is often exactly the physics the paper is explaining, e.g. which element breaks the symmetry). Instead, name each distinct shaped element with its own brief geometric descriptor and its own dimensions when given, joined with "/" inside one parenthesized group for that shared layer -- e.g. "Si(crossed rod 700x100nm / four fan-shaped blocks r=185-200nm, h=200nm) + SiO2" -- so a reviewer can see every element the unit cell actually contains, not just its shared material and height.
